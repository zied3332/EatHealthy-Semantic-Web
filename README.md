# EatHealthy — Semantic Web Project

EatHealthy is an ontology-driven nutrition recommendation
platform developed as part of the Semantic Web course at ESPRIT.

## Technologies

- Protégé
- RDF / RDFS / OWL
- SPARQL
- Apache Jena Fuseki
- Python / FastAPI (planned)
- React / TypeScript (planned)
- AI-powered semantic search (planned)

## Project Status

- [x] Initial ontology created in Protégé
- [ ] Validate ontology with HermiT
- [ ] Configure Apache Jena Fuseki
- [ ] Implement SPARQL queries
- [ ] Develop backend API
- [ ] Develop frontend
- [ ] Integrate AI-powered search
- [ ] Final integration and testing

## Project Structure

- ontology/ — RDF and OWL ontology files
- sparql/ — SPARQL queries
- backend/ — Python API
- frontend/ — React application
- docs/ — Project documentation
